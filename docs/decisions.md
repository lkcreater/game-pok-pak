# Decisions

บันทึกการตัดสินใจ ใหม่สุดอยู่บน รูปแบบ: ตัดสินใจ / เหตุผล / ทางเลือกที่ไม่เลือก

## 2026-11-19 — ไอเทมพิเศษ 3 อย่าง (laser / shield / bomb) ในทุกด่าน
- **ตัดสินใจ:** เพิ่ม `GameActions` 3 คำสั่ง (`laser`, `setShield`, `setBomb`) + entry ใน `ITEMS`; ใส่ทั้งสามใน `guaranteed` ของทุกด่าน; รวมการทุบบล็อกไว้ที่ `breakIfBrick` ที่เดียว (คะแนน/ดรอป/renderer ใช้ร่วมกัน); ตั้ง par/ดาวใหม่จากการจำลอง
- **เหตุผล:** ผู้ใช้ขอไอเทมพิเศษ 3 อย่างทุกด่าน; การันตีทำให้ได้เจอทุกด่านแน่นอน; เลือกผลที่ต่างจากไอเทมเดิมชัดเจน (ทำลายเป็นแนว / กันตก / ระเบิดเป็นวง)
- **ไม่เลือก:** ใส่ใน pool แบบสุ่ม (อาจไม่เจอเลย), เลเซอร์หยุดที่กำแพง (กรอบล่างบังเกือบทั้งหมด ไอเทมจะไร้ค่า)

## 2026-11-19 — เพิ่มอัตราดรอปไอเทมเป็น 2 เท่าทุกด่าน
- **ตัดสินใจ:** dropChance ตามระดับ 6/4/3/2% → 12/8/6/4%; ตั้ง `par` และดาวใหม่จากการจำลอง (ด่านผ่านเร็วขึ้นราว 30–50%, คะแนนสูงขึ้นจากไอเทม)
- **เหตุผล:** ผู้ใช้ขอให้ได้ไอเทมบ่อยขึ้นทุกด่าน; คงลำดับความยากระหว่างระดับไว้ด้วยการคูณเท่ากันทุกระดับ

## 2026-11-19 — 20 ด่าน เรียงตามความยากที่วัดได้
- **ตัดสินใจ:** เพิ่ม 17 ด่านรูปแบบต่างกัน (แผนที่ ASCII สร้างครั้งเดียวด้วยสคริปต์ทิ้ง แล้ว commit เป็นตัวอักษร); เรียงลำดับตามเวลาผ่านด่านจากการจำลอง 6 seed; ไอเทมผูกกับระดับ (ตำแหน่ง) ไม่ใช่รูปทรง; `par` = ~1.4 × เวลากลาง, 2★ ≈ คะแนนกลาง, 3★ ≈ คะแนนดีสุด
- **เหตุผล:** ผู้ใช้ขอ 20 ด่านง่าย→ยาก รูปแบบต่างกัน; จำลองพบว่า "วังวน" 3 วงผ่านไม่ได้เลย จึงลดเหลือ 2 วงและหันช่องวงนอกลงล่าง; เขาวงกต/วังวน (ด่าน 19–20) บอทผ่าน 3/6 — ตั้งใจให้ยากสุด
- **ไม่เลือก:** สร้างด่านด้วยโค้ดตอน runtime (ขัดกับการเห็นหน้าตาด่านใน levels.ts), บล็อกแข็งหลายครั้ง (เพิ่ม legend — ยังไม่จำเป็น)

## 2026-11-19 — เริ่มด่านด้วยลูกเดียว + เส้นขอบจอ
- **ตัดสินใจ:** ทุกด่าน `balls: 1` (ผู้ใช้ขอ); ด่าน 1 เจาะโพรงเหนือช่องล่าง; ลดเกณฑ์ดาวตามผลจำลองใหม่; วาดเส้นขอบซ้าย/บน/ขวา + เส้นประแดงขอบล่าง และพื้นที่เล่นสีอ่อนกว่าหน้าเว็บ
- **เหตุผล:** ลูกเดียวทำให้ช่วงแรกช้า โพรงทำให้ลูกที่เข้าไปทุบได้หลายก้อนต่อรอบ; จำลองด้วยผู้เล่นที่เล็งเข้าช่อง ผ่านทุกด่านทั้ง 5 seed (ด่าน 1 ใน 21–59 วิ); ผู้ใช้ต้องเห็นว่าลูกจะชนขอบตรงไหน
- **ไม่เลือก:** วางไอเทมการันตีใกล้ช่อง (ขัดกติกาซ่อนแบบสุ่มที่อนุมัติแล้ว)

## 2026-11-19 — จูนด่านด้วย headless simulation
- **ตัดสินใจ:** แผนที่มีแถวว่างเหนือกรอบ 4 แถว, คงวงว่างระหว่างกรอบกับบล็อก, ช่องล่างด่าน 1 กว้าง 8, ลูกเริ่ม 6–8, dropChance 0.04; ตั้ง par/stars จากผลจำลอง 5 seed
- **เหตุผล:** วัดจริงพบว่าถ้าไม่มีที่ว่างเหนือกรอบ ลูกเข้าโพรงได้แค่ทางช่องล่าง 4 ช่อง เกมแทบไม่เดิน; ลบวงว่างแล้วแย่ลง (ลูกชนหน้าบล็อกแล้วเด้งออก) จึงคืนไว้
- **ไม่เลือก:** เพิ่มความเร็วลูก (กระทบ test/อุโมงค์), เปลี่ยนกติกาซ่อนไอเทมการันตี (ผู้ใช้อนุมัติแบบสุ่มแล้ว)

## 2026-11-19 — Docs Stop hook เทียบเวลาแก้ไฟล์ + marker
- **ตัดสินใจ:** `.claude/hooks/docs-check.sh` block การจบงานเมื่อไฟล์โค้ดถูกแก้หลัง docs ล่าสุด แล้ว touch `.claude/.docs-checked` เพื่อเตือนครั้งเดียวต่อรอบ
- **เหตุผล:** เช็คแค่ git status จะเงียบตลอดเมื่อ docs มีแก้ค้าง; ไม่มี marker จะเตือนซ้ำทุกครั้งหลังตอบว่าไม่ต้องแก้; ไฟล์ใน commit ที่เกิดหลัง docs/marker ก็นับด้วย เพราะ workflow ปกติ commit ก่อนจบ turn (tree สะอาดตอน Stop)
- **ไม่เลือก:** PostToolUse (ถี่เกิน), SessionEnd (สั่ง Claude ต่อไม่ได้)

## 2026-11-19 — App เป็น client-only (`next/dynamic` ssr:false)
- **ตัดสินใจ:** `app/page.tsx` โหลด `App` แบบไม่ prerender แล้วอ่าน localStorage ใน lazy `useState`
- **เหตุผล:** เลี่ยง hydration mismatch และ setState-in-effect; เกมคนเดียวไม่ได้ประโยชน์จาก SSR

## 2026-11-19 — ระบบไอเทม: ทะเบียนกลาง + guaranteed/pool ต่อด่าน
- **ตัดสินใจ:** `ITEMS` registry (`label`, `color`, `apply(GameActions)`); ด่านระบุ `guaranteed` (ซ่อนในบล็อกสุ่ม) และ `pool` (สุ่มดรอป)
- **เหตุผล:** ผู้ใช้ต้องการเพิ่มไอเทมง่ายและกำหนดไอเทมต่อด่าน; ไอเทมคูณลูก (`x3`) ทำให้ลูกถึงหลักร้อยตามภาพอ้างอิง

## 2026-11-19 — กติกาเล็กๆ ที่ Claude ตัดสิน
- ลูกตอนเริ่มยิงพร้อมกันทั้งหมด ไม่มีลูกสำรอง แพ้เมื่อลูกบนจอหมด
- `boardx1` ถาวรจนจบด่าน (+25%/ขั้น สูงสุด 2×), `fire` 8 วิ รีเซ็ตเมื่อรับซ้ำ, เพดาน 500 ลูก
- ลูกชนเซลล์ด้วยจุดศูนย์กลาง (ไม่คิดรัศมี) — พอสำหรับเซลล์ 12px

## 2026-11-19 — Stack

- **ไม่เลือก:** React วาด `<div>` ทุกบล็อก (ช้า), Phaser/Pixi (หนักเกิน), Tailwind (ไม่จำเป็น)

- **ไม่เลือก:** JSON + level editor, ด่านสุ่ม, เหรียญ/ร้านค้า (ผู้ใช้ยืนยันว่าดาว + best พอ)
