## ภาพรวม

เกมทุบบล็อกเล่นคนเดียวใน browser: บล็อกเหลืองเต็มกรอบกำแพงเทา กรอบมีช่องเปิดบน/ล่าง
ลูกบอลขาวจำนวนมากเข้าไปขังในโพรงแล้วกัดกินบล็อก ผู้เล่นคุมแป้นแดง รับไอเทมที่ร่วงลงมา

## หน้าจอ

`ใส่ชื่อ → เลือกด่าน → ในเกม → ผลด่าน` (state machine ใน `components/App.tsx`)

- **ใส่ชื่อ** — เติมชื่อสุ่ม (`AdjNoun-NNN`), 🎲 สุ่มใหม่, ยาวสุด 20, ว่างไม่ได้ ข้ามหน้านี้ถ้ามีชื่อในเซฟแล้ว
- **เลือกด่าน** — ดาว + best score ต่อด่าน, ด่านล็อกแสดง 🔒, ปุ่มเปลี่ยนชื่อ
- **ในเกม** — HUD: ชื่อ, ด่าน, คะแนน, เวลา, จำนวนลูก, ⏸, ออก
- **ผลด่าน** — ผ่าน/ลูกหมด, ดาว, คะแนน, best, ด่านต่อไป (ถ้าผ่านและมี) / เล่นซ้ำ / เลือกด่าน

## การควบคุม

เมาส์/นิ้วลากบน canvas = เลื่อนแป้น · คลิก/แตะ/Space = ยิงลูก · ←/→ = เลื่อนแป้น (600 px/s)
Esc/P = หยุด/เล่นต่อ · แตะขณะหยุด = เล่นต่อ · สลับแท็บ = หยุดอัตโนมัติ

## ด่าน (`lib/game/levels.ts`)

เพิ่มด่าน = เพิ่ม entry ใน `LEVELS` (ลำดับ array = ลำดับด่าน)

| field | ความหมาย |
|---|---|
| `id` | key ในเซฟ ห้ามเปลี่ยนหลังปล่อย |
| `map` | ASCII: `#` กำแพง, `B` บล็อก, `.` ว่าง — ทุกแถวยาวเท่ากัน |
| `balls` | ลูกตอนเริ่ม ยิงพร้อมกันทั้งหมด ไม่มีลูกสำรอง |
| `par` | วินาทีเป้าหมาย (time bonus) |
| `stars` | `[คะแนน 2★, คะแนน 3★]` |
| `items.guaranteed` | ไอเทมการันตี ซ่อนในบล็อกสุ่มก้อนละชิ้น |
| `items.pool` | ไอเทมสุ่มดรอป (ใส่ซ้ำ = น้ำหนักมากขึ้น) |
| `items.dropChance` | โอกาสดรอปจาก pool ต่อบล็อก (default 0.02) |

กติกาออกแบบแผนที่: เว้นแถวว่างเหนือกรอบและคอลัมน์ว่างข้างกรอบ ให้ลูกวนข้ามกรอบลงช่องบนได้;
เว้นวงว่าง 1 ช่องระหว่างกรอบกับบล็อก เพื่อให้ลูกที่เข้าไปแล้วติดอยู่ข้างใน

ด่านปัจจุบัน: `classic` บล็อกยักษ์ (1440 บล็อก, ช่องล่าง 8), `diamond` เพชร (612), `rooms` สี่ห้อง (1152)

## ไอเทม (`lib/game/items.ts`)

เพิ่มไอเทม = เพิ่ม entry ใน `ITEMS` (ถ้าต้องการพฤติกรรมใหม่ เพิ่ม method ใน `GameActions` + implement ใน `Game`)
รหัสผิดใน `levels.ts` = TypeScript error

| id | ป้าย | ผล |
|---|---|---|
| `x2` / `x3` | ×2 / ×3 | ลูกทุกลูกแตกเป็น n ลูก (เบนมุม ±15°, ±30°…) |
| `up1` / `up3` | +1 / +3 | ยิงลูกใหม่จากแป้น กระจาย ±20° |
| `boardx1` | <-> | แป้นยาว +25% ถาวรจนจบด่าน สูงสุด 2 เท่า |
| `fire` | 🔥 | 8 วินาที ลูกเจาะทะลุบล็อก (ยังเด้งกำแพง), รับซ้ำ = รีเซ็ตเวลา |

ไอเทมร่วงตรงลง 150 px/s รับด้วยแป้น ตกพ้นจอ = หาย · ลูกบนจอสูงสุด 500

## ฟิสิกส์ (`lib/game/engine.ts`)

fixed step 1/120 วิ, ลูกความเร็วคงที่ 360 px/s, เซลล์ 12 px · เคลื่อนแกน x ก่อนแล้ว y (จับมุมทแยง)
แป้น: มุมสะท้อน = ตำแหน่งที่โดน × 60° · ลูกขึ้นทะลุแป้นได้ · หลังสะท้อน |vy| ≥ 25% ของความเร็ว
ไม่มีการชนกันระหว่างลูก · ขอบซ้าย/ขวา/บนของโลกสะท้อน ขอบล่างเปิด

## คะแนน / ดาว / ปลดล็อก

บล็อก +10 · รับไอเทม +50 · ผ่านด่าน + `floor(max(0, par − วินาที) × 20)`
ดาว: ผ่าน 1★, ≥ `stars[0]` 2★, ≥ `stars[1]` 3★ · แพ้ = ไม่บันทึก
ด่านแรกเปิดเสมอ ด่าน i เปิดเมื่อด่าน i−1 มี ≥ 1★

## เซฟ (`lib/save.ts`)

localStorage key `pokpak:v1` → `{ name, levels: { [id]: { best, stars } } }` เก็บค่าสูงสุดเสมอ
เซฟเสีย/อ่านไม่ได้ → ค่าเริ่มต้น, entry ที่รูปร่างผิดถูกทิ้งทีละอัน, storage ใช้ไม่ได้ → เล่นได้แต่ไม่จำ
